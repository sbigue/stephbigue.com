# stephbigue.com

Personal landing page, hosted free on GitHub Pages.

- Edit `index.html`, commit, push — the site updates itself in about a minute.
- `CNAME` tells GitHub Pages to serve this at stephbigue.com (don't delete it).
- DNS lives at Squarespace: four A records on `@` pointing at GitHub Pages,
  plus a `www` CNAME to `sbigue.github.io`.
- This repo must stay public (free GitHub Pages requirement).
